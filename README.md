# Voilà Language Studio

Official repository for the Voilà Language Studio website. This project is a professional platform for a language school based in Canada, offering English and French courses.

## Live Website
The website is accessible at: https://voilalanguage.ca/

## Project Features
- Responsive design for mobile and desktop devices.
- Interactive English and French placement tests.
- Comprehensive course information for levels A1 through C2.
- Clean user interface built with HTML5 and CSS3.

## Technical Details
- Languages: HTML5, CSS3, JavaScript.
- Hosting: cPanel / Namecheap.
- Security: AutoSSL (Sectigo).

## Project Structure

This project consists of several directories and files organized for a clean web architecture:

- **Root Directory:**
  - `index.html`: The landing page featuring the school's overview and course highlights.
  - `placementTest.html`: The core assessment page for new students.
  
- **common/ Folder:**
  - `site.css`: The primary stylesheet that controls the global look and feel.
  
- **Placement test/ Folder:**
  - This directory contains specific assets and additional files used exclusively for the testing module (e.g., `Test.css`).
  
- **Other Assets:**
  - Includes various folders for images and supporting scripts to ensure a smooth user experience.
